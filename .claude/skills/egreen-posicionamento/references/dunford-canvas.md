# Canvas Dunford — template e exemplo preenchido

## Template (copiar e preencher)

| Bloco | Pergunta-guia | Preenchimento |
|---|---|---|
| 1. Alternativas competitivas | O que o cliente-alvo faria/usaria se este produto não existisse? | |
| 2. Atributos únicos | O que a empresa tem que as alternativas acima não têm? | |
| 3. Valor (e prova) | Que benefício real esses atributos geram? Qual a prova/evidência? | |
| 4. Mercado-alvo | Qual perfil específico de cliente mais se importa com esse valor? | |
| 5. Categoria de mercado | Como a empresa vai se descrever para ser entendida rapidamente? | |
| 6. Tendências relevantes (bônus) | Que tendência real do mercado torna essa posição mais urgente agora? | |

**Postura estratégica (da Fase 1):** [Líder / Desafiante / Nova categoria / Nicho]

**Positioning statement:**
> Para [mercado-alvo], que [necessidade], [empresa] é [categoria] que [diferencial], diferente de [alternativa principal], porque [prova].

## Exemplo preenchido (ilustrativo, genérico — não é caso real)

Cenário: uma ferramenta de agendamento para clínicas odontológicas pequenas.

| Bloco | Preenchimento |
|---|---|
| 1. Alternativas competitivas | Planilha manual + WhatsApp com a secretária; ou um software genérico de agenda (tipo Google Calendar) |
| 2. Atributos únicos | Confirmação automática por WhatsApp integrada ao prontuário; lembrete de retorno baseado em histórico do paciente |
| 3. Valor (e prova) | Redução de faltas (no-show) — precisa de dado real do cliente para preencher aqui, ex: "reduziu faltas em X% em clínicas piloto" |
| 4. Mercado-alvo | Clínicas odontológicas com 1-3 dentistas, sem equipe de TI dedicada |
| 5. Categoria de mercado | "Sistema de agenda e retenção de pacientes para clínicas pequenas" (não "CRM odontológico" — categoria muito ampla e já disputada por players maiores) |
| 6. Tendências | Aumento da concorrência entre clínicas pequenas por retenção de paciente, não só captação |

**Postura estratégica:** Nicho defensável — não disputa a categoria ampla de "software para clínicas" (ocupada por players grandes), mas domina o subsegmento de clínicas pequenas sem TI.

**Positioning statement:**
> Para clínicas odontológicas pequenas sem equipe de TI, que perdem receita com faltas de pacientes, [Produto] é o sistema de agenda e retenção que reduz no-show com lembretes automáticos por WhatsApp — diferente de planilhas manuais ou calendários genéricos — porque é feito para funcionar sem configuração técnica, direto da recepção.

## Erros comuns a evitar ao preencher o canvas

1. **Bloco de valor sem prova real** — "somos mais eficientes" não é prova. Peça ao usuário um número, case ou comparação concreta; se não existir ainda, sinalize a lacuna em vez de inventar.
2. **Mercado-alvo genérico demais** ("empresas que querem crescer") — force um recorte específico.
3. **Categoria escolhida por ambição, não por clareza** — uma categoria muito ampla ("plataforma de gestão empresarial") pode soar impressionante mas dificulta o cliente entender rapidamente o que a empresa faz.
4. **Pular a Fase 1 (Ries & Trout)** — preencher os blocos sem antes mapear a escada competitiva tende a produzir uma categoria que não reflete como o cliente realmente pensa sobre o mercado.

# Skyscraper Technique (Dean) — passo a passo detalhado

## Passo 1 — Encontrar o "arranha-céu" do nicho

Para o tema/palavra-chave alvo:
- Pesquisar o termo no Google e observar os primeiros resultados
- Se houver ferramenta de análise de backlinks disponível (Ahrefs, Semrush, Moz, etc.), identificar qual desses resultados tem mais backlinks/domínios de referência
- Sem ferramenta paga, usar como proxy: posição no ranking + sinais de qualidade (profundidade do conteúdo, atualização recente, menções em outros lugares)

## Passo 2 — Construir uma versão substancialmente melhor

Não é "reescrever com outras palavras" — é tornar genuinamente superior em pelo menos uma destas dimensões:
- **Mais atualizado**: dados, exemplos ou práticas mais recentes que o conteúdo original não tem
- **Mais completo**: cobre lacunas que o original deixa (perguntas não respondidas, casos não cobertos)
- **Melhor estruturado**: mais fácil de navegar, com exemplos práticos, visual mais claro
- **Dado original**: uma pesquisa, número ou caso que só essa peça tem

Checklist de qualidade antes de publicar:
- [ ] Um leitor que já leu o conteúdo original ganharia algo novo lendo este?
- [ ] Existe pelo menos uma coisa nesta peça que nenhum concorrente tem?
- [ ] O conteúdo resolve a dúvida do leitor sem forçá-lo a sair para completar a informação em outro lugar?

## Passo 3 — Outreach

1. Listar sites que já linkam para o conteúdo original (ferramenta de backlinks, se disponível, ou busca manual por menções)
2. Priorizar sites relevantes ao nicho, não qualquer site com tráfego
3. Mensagem de contato: direta, específica sobre por que a nova versão é útil para o link já existente, sem tom de exigência
4. Sugerir o lugar exato do artigo onde o link faria sentido, para reduzir o esforço de quem recebe o pedido

## Passo 4 — Nunca depender só de "publicar e esperar"

Todo conteúdo pensado para ranquear deveria ter, junto com o plano de publicação:
- Uma lista inicial de outreach (mesmo que pequena)
- Um canal de distribuição inicial (newsletter própria, redes sociais, comunidades relevantes)
- Um prazo para revisar performance e decidir se vale investir mais nele (atualizar, promover mais) ou deixar como está

## Outros formatos de conteúdo úteis (além do Skyscraper puro)

- **Checklist detalhado**: guia estruturado como lista de verificação prática de um processo
- **Curadoria/roundup**: reunir e organizar as melhores fontes/opiniões sobre um tema, com valor agregado de curadoria
- **Conteúdo de renovação**: atualizar uma peça antiga e já indexada em vez de sempre criar do zero — aproveita autoridade já acumulada pela URL
